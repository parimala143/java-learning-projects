# Expense Tracker

A simple console-based Expense Tracker developed using Java.

# Features

* Add expenses
* View expenses
* Calculate total expenses
* Save expenses to a text file
* Exit the application

# Concepts Used
* Java classes and objects
* ArrayList
* FileWriter
* Exception handling
* Loops
* Switch statement
* Conditional statements
* Scanner

# How to Run

* Compile:
javac src/ExpenseTracker.java

* Run:
java -cp src ExpenseTracker

The application can create an expenses.txt file when expenses are saved.

# Learning Purpose

This project was developed to practice Java Collections and basic File Handling along with Object-Oriented Programming.
